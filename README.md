## Asistente — OSO

OSO es el asistente de ventas de Honey: un osito de peluche (teddy bear) dulce y masculino. Atiende en la web y, a futuro, en WhatsApp. Saludo: «¡Hola! Soy OSO, tu osito de Honey 🧸 ¿En qué te ayudo hoy?»

## Cómo se actualiza este repo

La web se edita en el artefacto `honey-and-seduction` y se exporta a `index.html`. Los documentos se editan en la carpeta de trabajo `~/workspace/honey-seduction/` y se copian aquí. No duplicar: el repo es el registro público del proyecto; los documentos internos viven en la carpeta de trabajo y en Google Drive.
